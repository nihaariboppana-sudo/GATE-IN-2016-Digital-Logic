# GATE IN 2016 Logic Circuit Verification
**Author:** Nihaari Boppana

This repository contains the software implementation files for verifying the combinational logic network from the GATE IN 2016 curriculum.

## System Minimized Logic
Applying Boolean reductions reduces the 4-NAND-gate circuit down to:
**F = XY + Y'Z** (2-to-1 Multiplexer)

## Repository Structure
* `/GateMux.ino` - Standard High-Level Arduino C++ Code
* `/GateAsm.ino` - Low-Level Embedded Inline AVR Assembly
* `/main.tex` - Source LaTeX Documentation Code

# GATE IN 2016 Digital Logic Solutions 🧠

A C++ repository dedicated to implementing, analyzing, and solving digital logic problems from the 2016 GATE (Graduate Aptitude Test in Engineering) Instrumentation paper. 

## 🛠️ Built With
- **Language:** C++
- **Concepts:** Digital Electronics, Logic Gate Simulation, Boolean Algebra

## 📋 Project Scope
- Functional implementations of digital logic questions.
- Programmatic validation of logic circuits and state reduction problems.
- Code structures designed to simulate hardware behaviors via software execution.

## 🚀 How to Run
1. Clone the repository to your local machine.
2. Compile the source files using any standard C++ compiler (like `g++`).
